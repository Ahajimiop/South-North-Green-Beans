# Zhang HaoTian Personal Portfolio

ICT2215 personal portfolio website built with HTML and CSS.

## Website sections

- Home
- About
- Work: photography projects and an embedded YouTube video
- Contact: display-only form; messages are not sent

## Preview locally

Open this folder in VS Code, then right-click `index.html` and select **Open with Live Server**.

## Publish with GitHub Pages

Use **Settings → Pages → Deploy from a branch**, select **main** and **/(root)**, and save.

Keep `index.html` at the repository root. Preserve the `css` and `images` folders and file-name case.

Google Fonts and the embedded YouTube video require an internet connection.
